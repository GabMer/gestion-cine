# Sistema de Gestión de Cine

Proyecto base para administrar películas y la venta de entradas de un cine.
Actualmente incluye un servidor Express y una página de bienvenida con frontend en HTML, CSS y JavaScript vanilla.

## Requisitos

- Node.js 18 o superior
- npm

## Instalación y ejecución

```bash
npm install
npm run dev
```

El servidor estará disponible en [http://localhost:3000](http://localhost:3000).

Para ejecutar el servidor sin nodemon:

```bash
npm start
```
